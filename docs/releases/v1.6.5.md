# AV Control 1.6.5

## Polski

Studio pozwala ukryć przyciskiem **X** 100 rodzajów podpowiedzi i bloków instrukcji. Obejmuje to kartę podłączenia konwertera, ekspandery, protokoły, sygnały, kreatory, logikę, Python, edytor paneli, metrykę projektu, diagnostykę oraz ustawienia.

W **Ustawienia → Podpowiedzi i instrukcje** znajdziesz listę ukrytych bloków, wyszukiwanie, przywracanie pojedynczego bloku i **Przywróć wszystkie podpowiedzi**. Studio zapamiętuje wybór na tym stanowisku dla wszystkich projektów, także po restarcie. Zmiana jest synchronizowana między oknami Studio.

Wydanie zawiera sprawdzony **podręcznik Signal Workshop z 11 października 2026**: 206 stron PDF, 52 rozdziały, 4 dodatki i 77 ilustracji, a także program szkolenia obejmujący 10 sesji i 22 godziny. Instrukcja programu opisuje nowe ukrywanie i przywracanie podpowiedzi.

Pakiety zbudowano i sprawdzono lokalnie. Próby obejmują instalację Studio Windows, zamknięcie i ponowne uruchomienie z ukrytą podpowiedzią, przywracanie z ustawień, motywy jasny i ciemny, emulację dotyku, testy interfejsu, pakiet Player Linux, silnik ARM64 oraz aktualizację obrazu w emulatorze. Manifest, podpis ECDSA i SHA256 są osobnymi załącznikami. Instalatory Windows nie mają własnego podpisu Authenticode. Próby symulacji i emulacji nie potwierdzają fizycznej karty SD, HDMI, USB ani elektrycznej komunikacji z urządzeniami.

## English

Studio now has an **X** button for hiding 100 guidance topics and instruction blocks. These cover controller connections, network gateways, protocols, signals, wizards, logic, Python, panel editing, project records, diagnostics and settings.

Open **Ustawienia → Podpowiedzi i instrukcje** to search hidden guidance, restore an individual block or select **Przywróć wszystkie podpowiedzi** to restore everything. Studio remembers the choice on this workstation across projects and application restarts. Studio windows synchronize the preference.

The release includes the reviewed **Signal Workshop handbook revised on 11 October 2026**: a 206-page PDF, 52 chapters, four appendices and 77 illustrations, plus the ten-session, 22-hour training programme. The application instructions explain the new hide and restore controls.

Packages were built and verified locally. Tests cover installed Windows Studio, hiding across application restarts, restoration from settings, light and dark themes, simulated touch, interface acceptance, the Linux Player package, ARM64 runtime and an emulated image update. The manifest, ECDSA signature and SHA256 checksums are separate assets. Windows installers do not have an own Authenticode signature. Simulation and emulation do not establish physical SD, HDMI, USB or electrical device acceptance.
