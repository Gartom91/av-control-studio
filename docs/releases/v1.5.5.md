# AV Control 1.5.5 — Konta i logowanie / Accounts and sign-in

## Polski

- Ustawienia użytkowników: dodawanie, zmiana nazwy i roli, reset hasła oraz usuwanie z potwierdzeniem. Ochrona ostatniego administratora; edycja konta unieważnia jego wcześniejsze sesje.
- Każdy użytkownik może zmienić własne hasło. Administrator może resetować hasła wszystkich kont.
- Player, panel WWW i panel HDMI wymagają logowania. Opcjonalne **logowanie automatyczne na 30 dni** jest domyślnie wyłączone; wylogowanie jest dostępne z panelu. Hasło nie jest zapamiętywane.
- Klawiatura wysuwa się płynnie od dołu po wybraniu pola lub przeciągnięciu uchwytu; klawisze znaków mają jednakowe wymiary.
- Własna klawiatura ekranowa zgodna z motywem panelu. **Alt**: polskie znaki; **Shift**: wielkie litery i symbole; **Alt+Shift**: wielkie polskie litery. Bez dodatkowego rzędu znaków. Klawiatura fizyczna działa równolegle.
- Sesja panelu ma uprawnienia operatora, również przy użyciu konta administratora. Zmiana hasła odwołuje także zapamiętane logowanie innych paneli.
- Poprawka instalacji pakietów graficznych Raspberry Pi offline: zweryfikowane archiwa trafiają do izolowanej pamięci podręcznej APT. Usuwa przyczynę wycofania aktualizacji Runtime 1.5.4 na testowej 4B.
- [Ilustrowany podręcznik kont i klawiatury z modułem szkolenia 60 minut](../KONTA-I-LOGOWANIE-PL.md). Kurs offline oraz instrukcja HDMI zawierają nowe odsyłacze.

Pakiety Windows, Player Linux, nowy obraz SD i Runtime mają tę samą wersję. Wyniki testów i granice potwierdzenia sprzętowego opisuje [raport](../WERYFIKACJA-1.5.5.md). Fizyczny HDMI, USB dotyk i tty2 wymagają oddzielnego odbioru na podłączonym sprzęcie.

## English

- User settings: create, rename, change role, reset passwords and confirm deletion. The last administrator is protected; account edits revoke earlier sessions.
- Every user can change their own password; administrators can reset all users' passwords.
- Player, browser and HDMI panels require sign-in. Optional **30-day automatic sign-in** is off by default; sign-out is available inside the panel. Passwords are never remembered.
- The keyboard slides up from the bottom on field focus or handle drag, with equal character keys and matching theme.
- A themed onscreen keyboard uses **Alt** for Polish accents, **Shift** for uppercase and shifted symbols, and **Alt+Shift** for uppercase accents. No extra character row. Physical keyboards also work.
- Panel sessions have operator permissions even when signing in with an administrator account. Password changes revoke remembered sessions on other panels.
- Fixed offline installation of Raspberry Pi graphics dependencies: verified archives populate an isolated APT cache. This addresses the Runtime 1.5.4 rollback cause observed on the test Pi 4B.
- [Account guide](../ACCOUNTS-AND-LOGIN-EN.md) and illustrated Polish training supplement with a new 60-minute module, included in the offline course.

Windows packages, Linux Player, clean SD image and Runtime share this version. See the [verification report](../WERYFIKACJA-1.5.5.md) for results and hardware boundaries. Physical HDMI, USB touch and tty2 switching require separate checks on connected equipment.
