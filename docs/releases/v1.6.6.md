# AV Control 1.6.6 — HDMI i TAB5

**[Polski](#polski) · [English](#english)**

## Polski

### Co się zmieniło

- Naprawiono poziome pasy w lokalnym obrazie HDMI Raspberry Pi. Poprawny ekran na RPi 4B i monitorze 2560 × 1440 potwierdził właściciel po zastosowaniu poprawki na 1.6.5; teraz zmiana jest częścią obrazu i aktualizacji 1.6.6.
- Dodano oficjalną obsługę **M5Stack TAB5 ST7123**: kod parowania, potwierdzenie pełnego odcisku certyfikatu, wysyłanie wybranych stron z projektanta lub ustawień Studio, natywne kontrolki i grafikę 1280 × 720, bibliotekę do 32 paneli na FAT/exFAT oraz belkę z jasnością, dźwiękiem i wyborem panelu.
- Dostępne jest firmware **0.2.4**, paczka do pierwszego wgrania przez USB oraz plik aplikacji do aktualizacji przez Wi‑Fi. Kopia z SD wymaga potwierdzenia właściwego panelu przez kontroler przed sterowaniem. Poprawiono obsługę spóźnionych odczytów i poleceń oraz ograniczenia przeglądania biblioteki.
- Naprawiono przekraczanie limitu dwóch równoczesnych strumieni jednego TAB5. Rezerwacje są zwalniane również po anulowaniu lub błędzie odpowiedzi.
- Zaktualizowano README, instrukcje oraz podręcznik **Signal Workshop z 12 października 2026**: **217 stron PDF, 55 rozdziałów, cztery dodatki i 83 ilustracje**. Program obejmuje 22 godziny podstawy, opcjonalne HDMI 60 minut i TAB5 90 minut. Zachowano przycisk X do ukrywania instrukcji i przywracanie z ustawień.

### Instalacja i aktualizacja

Pobierz aplikację z sekcji **Assets**: `AV-Control-Studio-1.6.6-Windows-x64.exe`, `AV-Control-Player-1.6.6-Windows-x64.exe` lub `AV-Control-Imager-1.6.6-Windows-x64.exe`. Player Linux jest dostępny jako `.deb` i `.tar.gz`; publiczny pakiet wymaga CPython 3.13, GTK 3 i WebKitGTK 4.1.

Istniejący kontroler aktualizuj ze Studio pakietem `AV-Control-Runtime-1.6.6-arm64.zip`; aktualizacja zachowuje dane i instaluje poprawkę kiosku. Nową kartę przygotuj Imagerem lub obrazem `AV-Control-RPi-1.6.6-arm64.img.xz`. Zapis nowej karty usuwa jej zawartość. Instalator Imagera uruchamia się ręcznie i wymaga zgody Windows; automatyczna instalacja Imagera pozostaje wyłączona.

Dla TAB5 ST7123 pierwsze wgranie wykonaj z paczki `AV-Control-TAB5-ST7123-0.2.4.zip`, zgodnie z zawartą instrukcją i skryptem USB. Urządzenie z obsługą OTA 0.2.3 lub nowszą aktualizuj przez **Ustawienia → Panele M5Stack TAB5 → Firmware przez Wi‑Fi (OTA)**, wybierając **`AV-Control-TAB5-ST7123-0.2.4-OTA.bin`**. OTA zawiera tylko aplikację i zachowuje ustawienia, parowanie i kartę SD. Nie wybieraj do OTA bootloadera, tablicy partycji ani pełnego obrazu pamięci. [Instrukcja TAB5](../TAB5-PL.md).

Ten sam sprawdzony PDF jest dołączony do trzech aplikacji Windows, obrazu i aktualizacji ARM, dokumentacji oraz kursu offline. Pobranie samego kursu nie aktualizuje aplikacji. Starsze ilustracje zachowują pierwotne daty i wersje; nowe ekrany Studio oraz obrazy urządzeń mają osobno opisane pochodzenie.

### Weryfikacja i ograniczenia

Pakiety budowano na lokalnym Windows i Linux. **Wszystkie siedem bramek CI** działa na lokalnych runnerach `self-hosted` / `av-control-local` dla dokładnego commitu; manifest zapisuje ich nazwy i wyniki. Sprawdzenia obejmują TAB5, natywny kiosk, interfejs, pakiet Windows, Player Linux oraz silnik na Windows i Linux. Nie używano minut runnerów GitHub.

Próby lokalne obejmują instalację i odinstalowanie Studio/Playera, Imagera w Program Files, natywne interfejsy, CPython z wheel NumPy offline, silnik ARM64 oraz migrację starego aktualizatora z zachowaniem danych i powrotem po błędzie. PDF ma **217/217 indywidualnych ocen PASS**. [Raport wydania](../WERYFIKACJA-1.6.6.md).

Fizyczny odbiór HDMI dotyczy 1.6.5 z tą samą poprawką. Fizyczny TAB5 z firmware **0.2.3** przeszedł USB, OTA i przełączanie dwóch rzeczywiście różnych paneli z SD; **nowy plik 0.2.4 nie przeszedł jeszcze osobnego wgrania na urządzenie**. Pełna fizyczna aktualizacja 1.6.6, rozruch nowej SD, inne modele RPi, dotyk USB i elektryczna komunikacja wymagają osobnych prób. Nie deklarujemy 30 pełnych klatek na sekundę dla stu elementów zmieniających się jednocześnie.

Przegląd bezpieczeństwa wykazał problem limitu strumieni o niskiej wadze. Rzeczywiste żądania HTTP przed poprawką dopuściły cztery strumienie, a po poprawce dwa; pozostałe sześć żądań odrzucono. Nie wykazano awarii całego kontrolera. Podpis manifestu ECDSA, SHA256 i oznaczone wersją raporty są osobnymi załącznikami.

## English

### What changed

- Fixed horizontal corruption in the Raspberry Pi HDMI kiosk. The owner confirmed a readable display on a Pi 4B and a 2560 × 1440 monitor after applying the correction to 1.6.5. The correction is now included in the 1.6.6 image and runtime update.
- Added official **M5Stack TAB5 ST7123** support: pairing codes, full certificate fingerprint confirmation, selected-page uploads from Studio settings or the designer, native 1280 × 720 controls and graphics, a library of up to 32 panels on FAT/exFAT and a pull-down bar for brightness, sound and panel selection.
- Added firmware **0.2.4**, an initial USB installation package and an application binary for Wi‑Fi updates. An SD copy must be verified against the controller's current document before it can control the installation. Stale responses and queued commands are rejected, and library scanning is bounded.
- Fixed the per-device two-stream limit and response reservation cleanup on cancellation or failure.
- Updated READMEs, instructions and the **Signal Workshop handbook revised on 12 October 2026**: **217 PDF pages, 55 chapters, four appendices and 83 illustrations**. The programme has 22 core hours, optional 60-minute HDMI and 90-minute TAB5 modules. Guidance X buttons and restoration from settings are retained.

### Install and update

Use **Assets** to download `AV-Control-Studio-1.6.6-Windows-x64.exe`, `AV-Control-Player-1.6.6-Windows-x64.exe` or `AV-Control-Imager-1.6.6-Windows-x64.exe`. Linux Player is provided as `.deb` and `.tar.gz`; the public package requires CPython 3.13, GTK 3 and WebKitGTK 4.1.

Update an existing controller from Studio using `AV-Control-Runtime-1.6.6-arm64.zip`. The update preserves data and installs the kiosk fix. Prepare a new card with Imager or `AV-Control-RPi-1.6.6-arm64.img.xz`; writing a new card erases its contents. Run the Imager installer manually and approve Windows elevation; automatic Imager installation remains disabled.

For initial TAB5 ST7123 installation, use `AV-Control-TAB5-ST7123-0.2.4.zip` and follow its USB instructions and script. A device with OTA support from 0.2.3 or later can be updated through **Ustawienia → Panele M5Stack TAB5 → Firmware przez Wi‑Fi (OTA)** using **`AV-Control-TAB5-ST7123-0.2.4-OTA.bin`**. OTA contains only the application and preserves settings, pairing and SD contents. Do not select a bootloader, partition table or full flash image for OTA. [TAB5 instructions](../TAB5-PL.md).

The same reviewed PDF is included in all three Windows applications, the ARM image and update, documentation and offline course. Downloading the course alone does not update applications. Retained illustrations keep their original dates and versions; new Studio and device views identify their provenance separately.

### Verification and limitations

Packages were built on local Windows and Linux. **All seven exact-commit CI gates** use local `self-hosted` / `av-control-local` runners; the manifest records runner names and results. These cover TAB5, native kiosk, interface, Windows package, Linux Player and runtime on Windows and Linux. No GitHub runner minutes were used.

Local checks cover installed Studio/Player and uninstallation, Imager in Program Files, native interfaces, CPython with an offline NumPy wheel, ARM64 and old-updater migration with data preservation and health-failure rollback. The PDF has **217/217 individual PASS reviews**. [Release verification](../WERYFIKACJA-1.6.6.md).

Physical HDMI acceptance applies to 1.6.5 with the same correction. A physical TAB5 running **0.2.3** passed USB, OTA and switching two genuinely distinct SD panels; **the new 0.2.4 binary has not yet been flashed and separately accepted on hardware**. A complete physical 1.6.6 update, clean SD boot, other Pi models, USB touch and electrical device communication need separate trials. There is no promise of 30 full frames per second for one hundred simultaneously changing widgets.

Security review identified a low-severity stream admission issue. Real HTTP requests admitted four streams before the correction and two afterwards, rejecting the six additional requests. A controller-wide outage was not demonstrated. The ECDSA manifest signature, SHA256 checksums and versioned reports are separate assets.
