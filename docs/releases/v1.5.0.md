## Polski

### Co się zmieniło

- **Signal Workshop:** jeden obszar pracy dla symboli urządzeń, sygnałów i stanów, protokołów, komend, sekwencji oraz Python. Kontekstowe formularze i kreatory prowadzą od połączenia do komendy i jej potwierdzenia. Urządzenia mają własne nazwy i ikony.
- **Czytelna logika:** porty leżą przy odpowiadających etykietach, trasy omijają symbole, osobne sygnały mają rozdzielone odcinki, a przecięcia są oznaczone. Bramki o zmiennej liczbie wejść, impulsowy Interlock z SET ALL/CLEAR oraz konfigurowalny Truth table.
- **Pełny Python i biblioteki:** edytor kodu, typowane porty, parametry, własne pliki pomocnicze i dokładne wersje zależności. Instalacja z PyPI lub zgodnych wheel offline, także NumPy. Środowiska użytkownika są oddzielone od systemowego Pythona. Zmiana kodu, helpera lub wymagań unieważnia zatwierdzenie administratora. Pełny CPython uruchamia zaufany kod z uprawnieniami procesu wykonawczego; nie jest sandboxem bezpieczeństwa.
- **Debugger:** obserwowane sygnały, ich jakość, pamięci, timery, sekwencje, TX/RX, ślad zdarzeń i przyczyny blokad. Wymuszenia wejść oraz pauza/krok skanów symulatora. Pauza nie zatrzymuje komunikacji, trwających sekwencji ani workerów Python.
- **Panele i wygląd:** osiem odmiennych motywów, subtelne wypukłości/gradienty Soft Dark oraz rzeczywiste efekty Glass, Liquid, Frost i Szron. Grafiki z dysku, ukrywanie etykiet, ramki, zaokrąglenia, CSS i wspólny renderer podglądu/operatora. Jasny, ciemny i systemowy motyw aplikacji z dopasowanymi paskami przewijania.
- **Prawy klik i skróty:** wytnij/kopiuj/wklej, duplikacja, usuwanie, zmiana nazwy, cofanie, wyrównywanie, grupowanie, warstwy, kopiowanie wyglądu, blokada położenia oraz przejście do końców przewodu. Kopiowanie między projektami przenosi wymagane powiązania.
- **Pakiety:** nowy kod produktu jest kompilowany; publiczne wydanie nie zawiera archiwum źródeł aplikacji. Minimalne launchery zachowują zgodność z updaterem 1.4.1. Imager instaluje się na koncie użytkownika; UAC jest wymagany przy zapisie karty.
- **Szkolenie:** nowy podręcznik Signal Workshop — **153 strony, 37 rozdziałów, cztery dodatki i 59 ilustracji**. Program: osiem sesji, około 19 godzin. Pięć neutralnych projektów, w tym Wirtualna sala i prezentacja materiałów panelu. Rozdziały opisują zakupione Y-105, USR-W610 i CH343P, USB–Ethernet, ekspandery, domyślny UART oraz Python/NumPy.

## English

### What changed

- **Signal Workshop:** a shared Logic workspace for device symbols, signals and states, protocols, commands, sequences and Python. Contextual forms and wizards connect a device to its command and acknowledgement. Devices have editable names and icons.
- **Readable diagrams:** ports align with labels, connections route around symbols, separate signals use separated segments and crossings are marked. Variable-input gates, a pulse Interlock with SET ALL/CLEAR and configurable Truth table.
- **Full Python and libraries:** code editor, typed ports, parameters, helper files and exact dependency versions. Install from PyPI or compatible offline wheels, including NumPy, in environments separate from system Python. Changing code, helpers or requirements invalidates administrator approval. Full CPython runs trusted code with the execution process's permissions; it is not a security sandbox.
- **Debugger:** watched signals and quality, memories, timers, sequences, TX/RX, event trace and blocking reasons. Input forcing and pause/single-step of simulator logic scans. Pausing does not stop communication, running sequences or Python workers.
- **Panels and appearance:** eight distinct themes, subtly raised Soft Dark controls and live Glass, Liquid, Frost and Rime effects. Import images, hide labels, adjust borders/corners/CSS and use the same renderer in preview and operation. Light, dark and system application themes with matching scrollbars.
- **Context menus and shortcuts:** cut/copy/paste, duplicate, delete, rename, undo, alignment, groups, layers, appearance copying, position locks and connection-end navigation. Cross-project copying transfers required dependencies.
- **Packages:** new product implementation is compiled; no application-source archive is distributed. Minimal launchers remain compatible with the 1.4.1 updater. Imager installs in the user's account; disk writing requires Windows UAC.
- **Training:** the new Polish Signal Workshop course has **153 pages, 37 chapters, four appendices and 59 illustrations**. Eight sessions, about 19 hours, plus five neutral example projects. It covers Y-105, USR-W610, CH343P, USB–Ethernet, serial gateways, default UART and Python/NumPy. Detailed training and the UI are currently in Polish.

Windows requires x64 and Windows 10 22H2 or Windows 11; .NET and the offline WebView2 installer are bundled. Linux/Pi bytecode requires a matching Python minor ABI. The public Linux Player targets 3.13; Ubuntu 24.04/3.12 CI is a separate test.

Apps and Pi controllers continue to obtain updates from this public repository. Runtime updates preserve existing controller data and roll back after a failed startup health check. Fresh images enable UART without a serial console; imaging erases the card. Studio checks older controller capabilities before deploying features requiring 1.5.

Windows wheels cannot replace ARM64 wheels. PyPI installation requires internet; compatible local wheels support offline setup. Define hardware commands and automatic startup actions in your own project. Examples use simulation and disabled hardware transports.
