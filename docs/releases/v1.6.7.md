### Co się zmieniło

Wydanie z 18 października 2026 usuwa wszystkie **25 ustaleń audytu**. Wersja aplikacji to **1.6.7**, a firmware TAB5 ST7123 to **0.2.5**. Do poprawek dodano testy regresji; poniższe identyfikatory zachowują powiązanie z audytem.

### Instalacja i aktualizacja

Z [załączników wydania](https://github.com/Gartom91/av-control-studio/releases/tag/v1.6.7) pobierz `AV-Control-Studio-1.6.7-Windows-x64.exe`, `AV-Control-Player-1.6.7-Windows-x64.exe` lub `AV-Control-Imager-1.6.7-Windows-x64.exe`. Player Linux jest dostępny jako `AV-Control-Player-1.6.7-Linux-all.deb` i `AV-Control-Player-1.6.7-Linux.tar.gz`; wymaga CPython 3.13, GTK 3 i WebKitGTK 4.1.

Studio loguje właściciela lokalnego symulatora automatycznie. Unikalne poświadczenie jest chronione przez Windows DPAPI i nie stanowi wspólnego hasła do wpisywania. Po wylogowaniu użyj **Otwórz lokalny symulator**; zmiana nazwy właściciela zachowuje tę możliwość. Po świadomej zmianie jego hasła użyj zwykłego formularza i własnego hasła. Do Playera utwórz operatora z własnym hasłem w **Ustawienia → Użytkownicy**. Konta kontrolera Raspberry Pi nadal używają haseł nadanych podczas konfiguracji.

Istniejący kontroler aktualizuj ze Studio pakietem `AV-Control-Runtime-1.6.7-arm64.zip`. Nową kartę przygotuj Imagerem lub `AV-Control-RPi-1.6.7-arm64.img.xz`; zapis karty usuwa jej zawartość. Instalator Imagera uruchamia się ręcznie i wymaga zgody Windows; automatyczna instalacja Imagera pozostaje wyłączona.

Pierwsze wgranie TAB5 ST7123: `AV-Control-TAB5-ST7123-0.2.5.zip`. Aktualizacja Wi‑Fi: **Ustawienia → Panele M5Stack TAB5 → Firmware przez Wi‑Fi (OTA)** i plik `AV-Control-TAB5-ST7123-0.2.5-OTA.bin`. OTA zawiera samą aplikację i zachowuje ustawienia, parowanie i SD. Nie używaj bootloadera, tablicy partycji ani pełnego obrazu jako OTA. Zabezpieczony panel wymaga odblokowania konfiguracji hasłem na urządzeniu przed zmianami przez USB; pierwsze przygotowanie bez ustawionego hasła pozostaje osobnym etapem. [Instrukcja TAB5](../TAB5-PL.md).

[Kurs offline](https://github.com/Gartom91/av-control-studio/releases/download/v1.6.7/AV-Control-Szkolenie-1.6.7.zip) i [PDF](https://github.com/Gartom91/av-control-studio/releases/download/v1.6.7/AV-Control-Studio-Tutorial-PL-Signal-Workshop.pdf) są dostępne osobno i w pakietach. Pobranie kursu nie aktualizuje aplikacji.

### Weryfikacja i ograniczenia

Regresje obejmują wszystkie 25 ustaleń: rzeczywisty silnik i dekoder, transporty testowe, kolejki i awarie, odzyskiwanie aktualizacji na plikach tymczasowych, konfigurator, firmware oraz interakcje Chromium. Testy przeglądarkowe sprawdzają m.in. multi-touch, klawiaturę, odrzucone polecenia, opóźnioną publikację i odzyskanie sesji. Natywny kontrakt otwierania pliku ma test transakcyjny, a testy Studio obejmują prywatne logowanie oraz zmianę i przywrócenie nazwy właściciela bez zmiany hasła.

Potwierdzone wyniki lokalne: **588 zaliczonych / 29 pominiętych** na Windows, **110 zaliczonych** w dodatkowym zestawie Linux, **6 zaliczonych** portable C++ TAB5 i **21/21** scenariuszy Chromium. Instalacja oraz natywne próby Studio, Playera i Imagera zakończyły się powodzeniem; nie zapisywano fizycznej karty. [Raport 1.6.7](../WERYFIKACJA-1.6.7.md) i [mapowanie 25 ustaleń](../AUDYT-NAPRAWY-1.6.7.md) podają dowody, tożsamość pakietów i ograniczenia. [Końcowe CI](../evidence/release-ci-1.6.7.json) zakończyło się **PASS 7/7** dla commitu `5e60c8438956137d91dd42b2fab7919bcf8b9ce8`: Windows **588 zaliczonych / 29 pominiętych**, Linux **611 zaliczonych / 6 pominiętych** oraz **4 zaliczone** izolowane próby root bootstrap. [Podpis ECDSA i komplet 49 plików sprawdzono lokalnie](../evidence/release-signing-1.6.7.json); [manifest wydania](https://github.com/Gartom91/av-control-studio/releases/download/v1.6.7/RELEASE-MANIFEST.json) ma zostać opublikowany wraz z paczkami. Publikacja i publiczne pobrania wymagają osobnego raportu po ich wykonaniu. Podręcznik ma osobny raport renderu, sumy PNG i indywidualny przegląd stron; historyczne testy wcześniejszych ilustracji nie są nowymi wynikami 1.6.7.

Historyczny odbiór HDMI dotyczy poprawki zastosowanej na **1.6.5** i dołączonej do 1.6.6. Fizyczny TAB5 z firmware **0.2.3** przeszedł USB, OTA i przełączanie dwóch paneli z SD. Te dowody **nie potwierdzają** nowego fizycznego odbioru 1.6.7 ani firmware 0.2.5. Pełna aktualizacja fizycznego RPi, rozruch nowej SD, inne modele RPi, dotyk USB i elektryczna komunikacja wymagają osobnych prób. Testy programowe i emulacja nie zastępują odbioru instalacji.

## English

### What changed

The 18 October 2026 release addresses all **25 audit findings**. Application version: **1.6.7**. TAB5 ST7123 firmware: **0.2.5**. Regression checks accompany the corrections; the identifiers below retain audit traceability.

| Audit ID | Corrected behavior |
| --- | --- |
| UI-01 | Momentary buttons release after the last touch ends and stop renewing their lease. |
| UI-02 | Disabled or cancelled knobs do not send a command when the pointer is released. |
| UI-03 | Publication completion preserves later edits and projects selected while it was pending. |
| UI-04 | The save destination changes only after the project has been read and accepted successfully. |
| UI-05 | Rejected actions restore switches to the confirmed state. |
| UI-06 | Numeric fields check range, step and numeric validity before sending. |
| UI-07 | The HDMI kiosk reloads its project after session loss, including an unchanged revision. |
| UI-08 | TAB5 supports action-only controls without requiring a signal binding. |
| UI-09 | Space and Enter hold and release momentary buttons; losing focus releases them. |
| R1 | Invalid timer parameters are rejected without stopping the controller loop. |
| R2 | A failed release action retains the lock against conflicting actions. |
| R3 | All fields from one received response are applied atomically. |
| R4 | Restored signal quality without a new value edge does not repeat an action. |
| R5 | Action blocks reject arguments with invalid quality. |
| R6 | Queued set actions recheck permission immediately before execution. |
| R7 | TCP listeners do not join frame fragments from separate connections. |
| R8 | Idle framing separates messages according to the configured gap. |
| R9 | Text-field offsets use the complete frame text, including surrounding spaces. |
| S-01 | A private owner credential replaces the shared local simulator password. |
| S-02 | The Raspberry Pi configurator rejects symbolic links instead of changing their targets’ permissions. |
| S-03 | USB configuration of a protected TAB5 requires local password unlocking. |
| P-01 | Interrupted rollback can resume while retaining the data backup needed for recovery. |
| P-02 | The API specification and project schema match current operations and the metadata field. |
| P-03 | Architecture documentation distinguishes the restricted interpreter from full trusted CPython. |
| P-04 | Build instructions identify the current image and package versions. |

The Signal Workshop handbook has **217 pages, 55 chapters, four appendices and 83 illustrations**. Its text now covers 1.6.7, including owner sign-in, USB configuration of TAB5 and protocol offsets. ### Install and update

Use the [release assets](https://github.com/Gartom91/av-control-studio/releases/tag/v1.6.7) to download `AV-Control-Studio-1.6.7-Windows-x64.exe`, `AV-Control-Player-1.6.7-Windows-x64.exe` or `AV-Control-Imager-1.6.7-Windows-x64.exe`. Linux Player is provided as `AV-Control-Player-1.6.7-Linux-all.deb` and `AV-Control-Player-1.6.7-Linux.tar.gz`, requiring CPython 3.13, GTK 3 and WebKitGTK 4.1.

Studio automatically signs the local simulator owner in. Its unique credential is protected by Windows DPAPI and is not a shared password to type. After signing out, select **Otwórz lokalny symulator**; renaming the owner preserves this ability. If you deliberately change the owner's password, use the ordinary sign-in form and your chosen password. Create a separate operator with your own password in **Ustawienia → Użytkownicy** for Player. Raspberry Pi controller accounts continue to use their configured passwords.

Update an existing controller from Studio with `AV-Control-Runtime-1.6.7-arm64.zip`. Prepare a new card with Imager or `AV-Control-RPi-1.6.7-arm64.img.xz`; writing a card erases its contents. Run the Imager installer manually and approve Windows elevation; automatic Imager installation remains disabled.

Initial TAB5 ST7123 installation uses `AV-Control-TAB5-ST7123-0.2.5.zip`. For Wi‑Fi updates, select **Ustawienia → Panele M5Stack TAB5 → Firmware przez Wi‑Fi (OTA)** and `AV-Control-TAB5-ST7123-0.2.5-OTA.bin`. OTA contains only the application and preserves settings, pairing and SD contents. Do not use a bootloader, partition table or full flash image for OTA. A protected panel must be unlocked locally with its configuration password before USB changes; first setup without a configured password remains a separate stage. [TAB5 instructions](../TAB5-PL.md).

The [offline course](https://github.com/Gartom91/av-control-studio/releases/download/v1.6.7/AV-Control-Szkolenie-1.6.7.zip) and [PDF](https://github.com/Gartom91/av-control-studio/releases/download/v1.6.7/AV-Control-Studio-Tutorial-PL-Signal-Workshop.pdf) are available separately and within the packages. Downloading the course does not update applications.

### Verification and limitations

Regression coverage addresses all 25 findings: the actual runtime and decoder, test transports, queues and failures, update recovery on temporary files, configurator, firmware and Chromium interactions. Browser checks include multi-touch, keyboard input, rejected commands, delayed publishing and session recovery. The native file-open contract has a transactional test; Studio checks cover private sign-in and renaming/restoring the owner without changing its password.

Confirmed local results: **588 passed / 29 skipped** on Windows, **110 passed** in the additional Linux suite, **6 passed** portable C++ TAB5 tests and **21/21** Chromium scenarios. Installation and native acceptance of Studio, Player and Imager succeeded; no physical card was written. The [1.6.7 verification report](../WERYFIKACJA-1.6.7.md) and [25-finding mapping](../AUDYT-NAPRAWY-1.6.7.md) identify evidence, package inputs and limits. [Final CI](../evidence/release-ci-1.6.7.json) finished **PASS 7/7** for commit `5e60c8438956137d91dd42b2fab7919bcf8b9ce8`: Windows **588 passed / 29 skipped**, Linux **611 passed / 6 skipped**, plus **4 passed** isolated root-bootstrap tests. [The ECDSA signature and all 49 files were verified locally](../evidence/release-signing-1.6.7.json); the [release manifest](https://github.com/Gartom91/av-control-studio/releases/download/v1.6.7/RELEASE-MANIFEST.json) is to be published with the packages. Publication and public downloads require a separate report after they complete. The handbook has separate rendering, PNG digest and individual-page review records. Historical tests for retained illustrations are not new 1.6.7 results.

Historical HDMI acceptance covers the correction applied to **1.6.5** and included in 1.6.6. A physical TAB5 running **0.2.3** passed USB, OTA and switching between two SD panels. That evidence **does not establish** new physical acceptance of 1.6.7 or firmware 0.2.5. A full physical Pi update, clean SD boot, other Pi models, USB touch and electrical communication require separate trials. Software tests and emulation do not replace installation acceptance.

### Distribution and licensing

Packages contain compiled applications, TAB5 binaries and documentation without a product source archive. The [ECDSA signature](https://github.com/Gartom91/av-control-studio/releases/download/v1.6.7/RELEASE-SIGNATURE.json) and [SHA256 checksums](https://github.com/Gartom91/av-control-studio/releases/download/v1.6.7/SHA256SUMS.txt) identify the packages. A manifest signature is not an installer Authenticode signature; AV Control installers do not have their own publisher signature. Historical MIT terms and component licenses remain intact. The future EULA plan does not activate new fees or update conditions.
