# AV Control 1.5.4 — HDMI operator panel / Lokalny panel HDMI

## Polski

- Raspberry Pi automatycznie wyświetla opublikowany panel po wykryciu monitora HDMI. Bez monitora nie uruchamia grafiki; po odłączeniu zatrzymuje sesję.
- Obsługa myszy, touchpada i ekranu dotykowego USB przez Linux/libinput. Monitor dotykowy zwykle wymaga osobnych przewodów HDMI oraz USB.
- Kiosk pokazuje wyłącznie panel operatora: blokuje menu kontekstowe, inne strony i okna, wybór/pobieranie plików oraz gesty historii. Nie udostępnia Studio, pulpitu ani ustawień połączenia.
- Klawiatura: **Ctrl+Alt+F2** otwiera konsolę tty2 wymagającą własnego logowania; **Ctrl+Alt+F1** wraca do panelu.
- Ustawienia WWW: automatyczne wyświetlanie, strona początkowa i stan HDMI. Projekt, konta oraz interlocki działają wspólnie z pozostałymi panelami.
- Nowy obraz i pakiet aktualizacji zawierają wszystkie pakiety graficzne. Kiosk działa na osobnym koncie operatora z lokalnym, krótkotrwałym kluczem i weryfikacją certyfikatu.
- [Instrukcja ze screenshotem i modułem szkolenia 60 minut](../PANEL-HDMI-PL.md). Dotychczasowy podręcznik PDF pozostaje częścią pakietu; nowy materiał HDMI jest osobnym dodatkiem.

Weryfikacja obejmuje natywny GTK/WebKit w wirtualnej sesji Cage Wayland, utratę połączenia, blokady nawigacji, brak odtwarzania komend, logikę wykrywania HDMI i skład obrazu ARM64. **Fizyczny monitor HDMI, wejścia USB i przełączenie tty2 wymagają osobnego odbioru sprzętowego.** Wyniki i ograniczenia: [raport wydania](../WERYFIKACJA-1.5.4.md).

## English

- Raspberry Pi automatically displays the published operator panel when an HDMI monitor is detected. Graphics are stopped while no monitor is connected.
- Linux/libinput-supported USB mouse, touchpad and touchscreen input. Touchscreens usually require separate HDMI video and USB touch cables.
- Operator-only kiosk: context menus, other pages/windows, file dialogs/downloads and browser history gestures are blocked. No Studio, desktop or connection settings UI.
- **Ctrl+Alt+F2** opens the tty2 console with normal OS login; **Ctrl+Alt+F1** returns to the panel.
- Web administration offers automatic display, initial-page selection and HDMI status. The same project, accounts and interlocks serve local and remote panels.
- Clean image and Runtime update include all graphics dependencies. A dedicated unprivileged operator account uses a short-lived local credential and certificate verification.
- [HDMI guide](../HDMI-PANEL-EN.md) and illustrated Polish 60-minute training supplement. The existing PDF handbook remains included; HDMI training is a separate supplement.

Validation covers native GTK/WebKit on a virtual Cage Wayland output, offline recovery, navigation restrictions, restart without command replay, hotplug supervisor and ARM64 image contents. **Physical HDMI, USB input and tty2 switching remain separate hardware acceptance tests.** See the [verification report](../WERYFIKACJA-1.5.4.md).
