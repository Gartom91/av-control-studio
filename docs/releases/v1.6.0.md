# AV Control 1.6.0

## Polski

Podgląd roboczej logiki odświeża się co około 200 ms i po zmianach sygnałów, stałych wejść, połączeń oraz Cofnij/Ponów. Używa tego samego silnika bez publikowania i bez wykonywania poleceń. Oddzielny tryb pokazuje stan opublikowanego programu; debugger nadal odnosi się do aktywnej wersji. Pełny CPython uruchamiaj przez zatwierdzony test lub symulator.

UDP ma teraz wyjście Gniazdo UDP gotowe, TCP — Połączenie TCP, port szeregowy — Port otwarty. Osobna Odpowiedź aktualna wymaga poprawnie dopasowanej odpowiedzi i ustawionego czasu ważności; dane nieznane i przeterminowane nie potwierdzają urządzenia. Domyślny systemowy TCP keepalive (30 s / 10 s / 3 próby) bada istniejący socket bez poleceń protokołu. Socket do ekspandera nie potwierdza jego odbiornika RS; otwarty USB-RS232 nie wykrywa odpięcia kabla DB9.

Klawiatura ekranowa i jej uchwyt są domyślnie ukryte przy wejściu przez WWW z PC. Można je włączyć w ustawieniach wprowadzania tekstu, także z konta operatora i przed logowaniem. Wybór jest lokalny dla przeglądarki; panel HDMI Raspberry Pi domyślnie udostępnia klawiaturę.

Nowy ekran powitalny zbiera projekty, przykłady i szkolenie. Karta Projekt zawiera odrębną metrykę instalacji: klienta, obiekt, zakres, zespół, kontakty, terminy, dokumenty, listę odbiorową, historię zmian i eksport. Dane zachowują się w .avctrl; panel operatora nie otrzymuje prywatnej metryki.

Diagnostyka działa autonomicznie na Raspberry Pi. Obserwuje komunikację, brak poprawnych odpowiedzi, błędy ramek, reconnecty, kolejki, logikę/Python, usługi, temperaturę, zasilanie, RAM, dysk, zegar i certyfikat. Opcjonalne odczyty kontrolne korzystają z normalnych akcji, kolejki i interlocków. Brak zezwolenia lub zajęta kolejka nie oznaczają poprawnego pomiaru.

Agent 1.1.0 zachowuje lokalną historię incydentów i trwałą kolejkę raportów. Integracja TECHNIKAV wymaga hostingu obsługującego protokół diagnostyki 1: raporty, uprawnienia, popup po logowaniu i opcjonalna poczta skonfigurowana przez właściciela. Starszy hosting zachowuje zwykły heartbeat; nowy moduł nie wysyła do urządzeń poleceń podczas oglądania diagnostyki.

Właściwości strony panelu pozwalają wybrać kolor, gradient liniowy/promienisty/stożkowy lub wgrać obraz bezpośrednio z listy. Obsługiwane są skalowanie, pozycja, kadrowanie źródła, dopasowanie, rozciąganie, powielanie na obu lub jednej osi, własne wymiary, krycie i nakładka. Podział 9-slice zachowuje narożniki i pozwala dobrać sposób wypełniania krawędzi oraz środka. Te same ustawienia obsługują edytor, Player i kiosk HDMI.

Zaktualizowany główny podręcznik: 52 rozdziały, 4 dodatki, 72 ilustracje i 191 stron PDF, z jednym spisem treści i HTML offline. Program obejmuje 10 sesji / 22 godziny. Konta, wysuwana klawiatura, metryka, diagnostyka i tła są opisane w tym samym dokumencie; osobny suplement usunięto.

Granice: bieżące metryki i historia incydentów nie są pełnym archiwum każdej próbki. Przy długim braku Internetu przekroczenie budżetów raportowania jest oznaczane lukami. E-mail wymaga konfiguracji i harmonogramu hostingu; testy z transportem zastępczym nie potwierdzają rzeczywistego dostarczenia. Próby programowe są oddzielone od odbioru fizycznego sprzętu.

Poprawiono dostęp konta kiosku do katalogu programu i publicznych zasobów WWW po aktualizacji z prywatnym umask. Obraz sprawdza odczyt interfejsu i importy ARM jako rzeczywiste konto avctrl-panel; prywatne dane i poświadczenia zachowują ograniczone uprawnienia.

## English

Draft logic refreshes about every 200 ms and after signal, unconnected input, constant, connection and undo/redo changes. It uses the same engine without deployment or command execution. A separate mode shows the published program; the debugger still observes the active version. Run full CPython through an approved test or simulator.

UDP now reports UDP socket ready, TCP reports TCP connection, and serial reports Port open. A separate Reply current output requires a protocol-matched reply and a configured expiry; unknown or stale data cannot confirm device presence. Default kernel TCP keepalive (30 s idle / 10 s interval / 3 probes) checks the existing socket without application commands. A gateway socket does not prove its downstream serial receiver; an open USB-RS232 adapter cannot detect an unplugged DB9 cable.

The onscreen keyboard and its handle are hidden by default when accessing the web interface from a PC. Enable them in text input settings, including operator account and sign-in settings. This browser preference is independent of the native Raspberry Pi HDMI panel, where the keyboard is enabled by default.

The welcome screen brings together projects, examples and training. The separate Project page records the installation, client, scope, team, contacts, dates, documentation, handover checklist and change history. Records survive .avctrl export; private project metadata is excluded from operator panels.

Autonomous Raspberry Pi diagnostics observe transports, valid replies, framing errors, reconnects, queues, logic/Python, services, temperature, power, memory, storage, clock synchronization and certificate expiry. Optional read-only probes use declared actions, device queues and interlocks. Deferred probes do not close an existing fault.

Agent 1.1.0 stores incidents and a durable acknowledged report queue. TECHNIKAV diagnostic protocol 1 adds scoped reports, login alerts and owner-configured email. Older hosting retains its ordinary heartbeat. Opening the diagnostic view does not send commands to devices.

The panel page inspector supports solid colours, linear/radial/conic gradients and image uploads directly from the asset selector. Image controls include scaling, positioning, source cropping, cover/contain/stretch, two-axis or single-axis tiling, custom dimensions, opacity and overlays. Nine-slice scaling preserves corners and offers stretch/repeat/round/space filling. The editor, Player and HDMI kiosk share the same renderer.

The main handbook now contains 52 chapters, 4 appendices, 72 illustrations and 191 PDF pages, one table of contents and an offline HTML edition. The training programme contains 10 sessions / 22 hours. Accounts, the sliding keyboard, project records, diagnostics and backgrounds are integrated into the original document; the separate supplement was removed.

Limits: current metrics and incident history are not a complete time series. Long outages may exhaust bounded queues; dropped reports remain visible. Email requires hosting configuration and a scheduled task. Software fixtures and mail stubs are reported separately from physical hardware and real message delivery.

Fixed unprivileged kiosk access to program files and public web assets after updates with a private umask. Image acceptance reads the UI and imports ARM modules as avctrl-panel; private data and credential permissions remain restricted.
