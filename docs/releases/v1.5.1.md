# AV Control 1.5.1 — Workspace & Debugger

**[Polski](#polski) · [English](#english)**

Studio · Player · Imager · Raspberry Pi Runtime **1.5.1** · Agent **1.0.4** | 2026-10-10

## Polski

- Przyciski **Projekt / Urządzenia / Panele / Logika** znajdują się po prawej stronie nagłówka. Selektor projektów jest bezpośrednio po ich lewej stronie i pozostaje dostępny w węższym oknie. Konto, motyw i ustawienia pozostają na prawym końcu nagłówka.
- Debugger można umieścić nad, pod, po lewej lub po prawej stronie schematu. Separator reguluje wysokość/szerokość; ustawienia są zapamiętywane. Dostępny jest pełny obszar roboczy oraz osobne okno Windows lub przeglądarki, także na drugim monitorze.
- Przenoszenie debuggera zachowuje obserwowane sygnały, kartę, filtr i zatrzymany ślad; okno działa podczas edycji innych kart. Zamknięcie okna przywraca debugger do Studio.
- Formularze urządzeń i konfiguracja Raspberry Pi wykorzystują pełną dostępną szerokość. Konfigurację otwartą z Logiki można rozwinąć na cały obszar.
- Naprawiono stan sekwencji anulowanej przed jej pierwszym krokiem oraz odpowiedź API podczas ponownego anulowania. Nie pozostaje pozornie działająca sekwencja ani zajęte zezwolenie przejściowe.
- Naprawiono uruchamianie skompilowanych narzędzi na RPi i usługi aktualizatora. Poprawka jest w aktualizacji silnika oraz nowym obrazie SD.
- Wydanie obejmuje Studio, Player, Imager, Linux Player, Runtime RPi, obraz SD oraz uaktualniony 154-stronicowy podręcznik i program szkolenia. Agent zachowuje wersję 1.0.4.

**Aktualizacja:** aplikacje Windows mogą sprawdzić wydanie w ustawieniach aktualizacji. Na kontrolerze wybierz **Sprawdź aktualizacje**, następnie **Zainstaluj 1.5.1**. Automatyczna instalacja RPi odbywa się w skonfigurowanym oknie nocnym; publikacja wydania nie oznacza natychmiastowej instalacji. Nie trzeba ponownie zapisywać karty SD istniejącego kontrolera.

## English

- **Project / Devices / Panels / Logic** navigation is right aligned. The project selector sits immediately to its left and remains available in narrower windows. Account, appearance and settings controls remain at the right edge.
- Place the debugger above, below, to the left or to the right of the diagram; drag the splitter to adjust its size. Layout preferences persist. Use the full workspace or detach to an independent Windows/browser window, including a second monitor.
- Detaching preserves watched signals, the active tab, filters and frozen traces. The window stays live while editing other sections; closing it restores the dock.
- Device and Raspberry Pi configuration forms use the available page width. Configuration opened from Logic can expand across the workspace.
- Fixed sequences cancelled before their first step and repeat-cancellation API responses. Cancelled sequences no longer retain a false running state or a transient permission.
- Fixed compiled RPi executable launchers and updater service startup in both the Runtime update and clean SD image.
- Includes Studio, Player, Imager, Linux Player, Pi Runtime, SD image and the updated 154-page Polish handbook and training course. Agent remains at 1.0.4.

**Updating:** check for Windows updates in application settings. On the controller, check releases and select **Install 1.5.1**. Automatic Pi installation uses the configured nightly maintenance window; publication does not mean immediate installation. Existing controllers do not require rewriting their SD cards.
