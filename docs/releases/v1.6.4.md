# AV Control 1.6.4

## Polski

Wydanie 1.6.4 dołącza **pełny podręcznik Signal Workshop z 11 października 2026** bez zmiany jego treści: 206 stron PDF, 52 rozdziały, 4 dodatki i 77 ilustracji. Ten sam materiał jest w instalatorach, obrazie Raspberry Pi, pakiecie dokumentacji i kursie offline. Program szkolenia obejmuje 10 sesji i 22 godziny.

Przegląd Daybreak i niezależny audyt wykazały problemy w sterowaniu akcjami, limicie żądań, przetwarzaniu archiwów, historii sekwencji i łańcuchu aktualizacji. Poprawiono kontrolę deklarowanych parametrów akcji oraz zgodność starszych paneli z suwakami, równoległe blokady sekwencji, limity aktywnych sekwencji i stanów sesji, odcinanie dużych żądań przed analizą JSON oraz rozpakowywanie archiwów projektu z limitem rozmiaru po dekompresji. Nowe aktualizatory Studio, Playera i RPi sprawdzają manifest podpisany niezależnym kluczem ECDSA oprócz SHA256 pakietu.

Imager 1.6.4 instaluje się w chronionym katalogu Program Files i wymaga potwierdzenia Windows UAC. Zapis karty SD z kopii uruchomionej poza tym katalogiem jest blokowany. **Automatyczna instalacja aktualizacji Imagera jest wyłączona**. Po ręcznym wybraniu aktualizacji w Imagerze podniesiony proces pobiera instalator do chronionego katalogu i sprawdza go z podpisanym manifestem przed uruchomieniem. Przy pierwszym przejściu z wersji 1.6.3 pobierz instalator z tej strony i niezależnie sprawdź jego sumę SHA-256; starszy program nie ma jeszcze wbudowanej weryfikacji podpisu.

Manifest wydania, podpis i sumy SHA256 są osobnymi załącznikami. Podpis manifestu nie jest podpisem Authenticode instalatorów Windows. Testy plików, symulacji i emulacji ARM nie potwierdzają uruchomienia na nowej fizycznej karcie SD, RPi 3B/5, elektrycznych połączeń RS/UART/GPIO, dotyku USB ani odporności na utratę zasilania. Odbiór aktualizacji na fizycznym RPi 4B będzie raportowany oddzielnie, jeśli zostanie wykonany.

## English

Version 1.6.4 embeds the **complete Signal Workshop handbook revised on 11 October 2026**, unchanged: a 206-page PDF, 52 chapters, four appendices and 77 illustrations. The installers, Raspberry Pi image, documentation archive and offline training package contain the same handbook. The training programme covers ten sessions and 22 hours.

Daybreak and an independent audit identified issues in action arguments, request limits, project archive handling, sequence state and update trust. This release restricts operator input to declared or administrator-bound action parameters while preserving older slider panels, fixes concurrent sequence locks, caps active sequences and stored sessions, rejects oversized requests before JSON parsing, and limits project ZIP expansion while streaming. New Studio, Player and Raspberry Pi updaters verify an independently signed ECDSA release manifest in addition to package SHA256.

Imager 1.6.4 installs in protected Program Files and requires Windows UAC. SD writes from a copy launched outside that directory are blocked. **Automatic Imager updates are disabled**. When an update is started manually in Imager, the elevated program downloads the installer into a protected directory and verifies it against a signed manifest before launch. For the first transition from 1.6.3, download the installer from this release and independently check its SHA-256 hash; the older program does not yet contain signature verification.

The release manifest, signature and SHA256 checksums are separate assets. A signed manifest is not an Authenticode signature on the Windows installers. File, simulation and ARM emulation tests do not establish a fresh physical SD boot, Pi 3B/5 operation, electrical RS/UART/GPIO links, USB touch or power-loss recovery. Physical Pi 4B update acceptance will be reported separately if completed.
