# AV Control 1.4.1 — extra LAN & serial gateways / dodatkowy LAN i ekspandery

## Polski

### Co się zmieniło

- **Dodatkowy LAN:** konfiguracja adapterów USB–Ethernet na RPi przez WWW administratora, wybór karty przez MAC i tymczasowa zmiana sieci wymagająca potwierdzenia.
- **Ekspandery RS232/RS485:** kreator kanałów Ethernet/Wi-Fi, osobne adresy i porty, TCP/UDP/RFC2217, parametry szeregowe, eksport planu i diagnostyka. Surowe TCP/UDP wymagają ustawienia parametrów szeregowych w panelu producenta.
- **Szkolenie:** pięć stron, dziesięć wyłączonych urządzeń i trzy bramki sieciowe w projekcie. Kurs: 116 stron, 32 rozdziały, cztery dodatki, 39 screenshotów i trzy schematy; nowe rozdziały o LAN i ekspanderach.
- **Naprawa aktualizacji Agenta:** obraz i Runtime zawierają kompletny bootstrap Agenta 1.0.3. Budowanie odrzuca brak wymaganych plików lub niezgodność wersji; aktualizacja nie pozostawia starego Agenta.
- **Domyślny UART:** włączony w czystym obrazie dla 3B/4B/5, bez konsoli szeregowej. Przypisania GPIO opisuje instrukcja UART.

### Instalacja i aktualizacja

Pobierz odpowiedni plik z **Assets**: Studio do projektowania, Player do samych paneli, Imager do karty SD. **Runtime ARM64** aktualizuje istniejący kontroler. Sprawdź SHA-256 przed ręczną instalacją.

Aplikacje zachowują dotychczasowy adres aktualizacji. RPi wykonuje kopię danych i wraca do poprzedniej wersji po nieudanym sprawdzeniu uruchomienia. Zapis obrazu usuwa zawartość karty; aktualizacja Runtime zachowuje dane istniejącej instalacji.

PDF i ZIP szkolenia mają w nazwie **1.4.0** i pozostają zgodne z **1.4.1**.

## English

### What changed

- **Additional LAN:** configure USB–Ethernet adapters on the Pi through the administrator web interface, select adapters by MAC and confirm temporary network changes.
- **RS232/RS485 gateways:** Ethernet/Wi-Fi channel wizard, individual addresses and ports, TCP/UDP/RFC2217, serial settings, configuration-plan export and diagnostics. Raw TCP/UDP requires applying serial settings in the manufacturer's interface.
- **Training:** five project pages, ten disabled devices and three network gateways. The course has 116 pages, 32 chapters, four appendices, 39 screenshots and three diagrams, including new LAN and gateway chapters.
- **Agent update fix:** the image and Runtime include the complete Agent 1.0.3 bootstrap. Builds reject missing required files or version mismatches; updates no longer leave the previous Agent installed.
- **Default UART:** enabled in the clean image for 3B/4B/5, with the serial console disabled. See the UART guide for GPIO assignments.

### Install and update

Download an **Asset**: Studio for authoring, Player for panels only, or Imager for an SD card. **Runtime ARM64** updates an existing controller. Check SHA-256 before manual installation.

Applications keep their existing update address. The Pi updater backs up data and rolls back after a failed startup check. Writing an image erases the card; a Runtime update preserves the existing installation's data.

The training PDF and ZIP retain **1.4.0** in their names and also apply to **1.4.1**. Detailed manuals and the UI are currently in Polish; these release notes are bilingual.

### Distribution and licensing

Packages were moved without changing their bytes; SHA-256 was checked against the original release. **DISTRIBUTION-MANIFEST.json** and **SHA256-DISTRIBUTION.txt** list the public files. Historical reports and the manifest remain unchanged; old source-history links may require private access.

The product source archive is excluded. GitHub's automatic “Source code” archives contain release documentation. Historical Python packages may contain readable Runtime code. The MIT terms for 1.4.1 remain unchanged; the proposed EULA does not activate fees or new terms for previously released copies.

Signal Workshop, the debugger and expanded Python are in development and are not included in the 1.4.1 packages.
